# الوحدات المستقلة

كل وحدة تُحمّل عند فتح التبويب الخاص بها عبر `src/app/router.js`.

في هذه المرحلة تعمل الوحدات كحدود مستقلة حول واجهة legacy الحالية، وتُسجّل الدوال القديمة المتاحة كـ fallback. هذا يمنع تغيير السلوك أثناء نقل الموقع تدريجياً، ويتيح نقل منطق كل وحدة إلى ملفاتها بدون تعديل بقية التطبيق.

الوحدات الحالية: الإدارة، المعلمون، الطلاب، الرصد، التسجيل السريع، التقارير، الملاحظات، المصاريف، وتسجيلات الشيوخ.
